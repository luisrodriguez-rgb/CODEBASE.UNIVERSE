## 1. Why CODEBASE.UNIVERSE?

### The "Particle Hairball" Problem
Traditional code visualization tools dump tens of thousands of unweighted dots into a spherical force-directed cloud. While visually dazzling for five seconds, they offer **zero architectural hierarchy**, **zero actionable insight**, and **zero refactoring utility**. You cannot see where execution starts, which module is a single point of failure, or how a breaking contract change cascades downstream.

### The Citadela Paradigm
**CODEBASE.UNIVERSE** treats software as a physical city:
- **Mass Encodes Code Complexity:** High-LOC God classes manifest as towering monoliths; lightweight utility functions sit as modular residential blocks.
- **Windows Encode Cyclomatic Debt:** Internal branching decisions (if/else/switch/catch) light up illuminated matrices across building facades.
- **Beacons Encode System Criticality:** Skyward vertical light beams project only from architectural landmarks (percentile 95+ betweenness centrality).
- **Zoning Encodes Runtime Boundaries:** Code is partitioned into 8 functional districts so UI never gets confused with database layers or transmission gateways.

### 04 // Threat Arena & Refactor Strategy Simulator
Automatically detects critical architectural anti-patterns and simulates non-destructive refactoring solutions:
- **The Death Star:** Monolithic components with excessive fan-out and tight coupling.
- **The Cyclic Wormhole:** Direct circular dependencies causing deadlocks and memory leaks.
- **The Single Point of Failure:** Fragile choke points with zero redundancy.
- **4 Actionable Decoupling Strategies:** `[ BREAK CYCLE ]`, `[ SPLIT MODULE ]`, `[ INTRODUCE INTERFACE (DIP) ]`, `[ ISOLATE SUBSYSTEM ]`.

## 7. Quick Start & Local Execution

CODEBASE.UNIVERSE is completely standalone, lightweight, and requires zero cloud dependencies:

```bash
# 1. Clone the repository
git clone https://github.com/luisrodriguez-rgb/CODEBASE.UNIVERSE.git
cd CODEBASE.UNIVERSE

# 2. Start the local server
node server.js

# 3. Open in your browser
# http://localhost:5173
```
