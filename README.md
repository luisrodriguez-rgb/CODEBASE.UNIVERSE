## 1. Overview & Core Philosophy

Traditional code visualization tools suffer from the **"Particle Hairball" problem**: dumping tens of thousands of unweighted nodes into a dense spherical cloud that dazzles for five seconds but offers zero architectural clarity or actionable refactoring value.

**CODEBASE.UNIVERSE** redefines code exploration by transforming repositories into **metric-driven procedural citadels**:
1. **Physical Scale Encodes Code Mass:** Towering megastructures represent high-complexity monoliths, illuminated window matrices reflect cyclomatic complexity, and skyward light beams highlight architectural landmarks.
2. **True Functional Zoning:** Repositories are organized into **8 Domain Biomes** reflecting real runtime boundaries (APIs, UI, State, Storage, Algorithms, Hazards, Legacy).
3. **Interactive Simulation & Impact Analysis:** Test refactoring hypotheses in real time with What-If cascade blackout simulations, Dijkstra-powered GPS trace paths, and detective incident investigations.

## 2. Ingestion Gateways & Ecosystem Support

CODEBASE.UNIVERSE supports three unified ingestion pipelines:

### Gateway 01: GitHub Cloud Importer (Live Git Tree API)
- Connect to any public repository via slug (e.g. `facebook/react`, `vuejs/core`, `pmndrs/zustand`, `luisrodriguez-rgb/CODEBASE.UNIVERSE`) or full GitHub URL (including custom branches like `owner/repo/tree/feature-branch`).
- Optional **GitHub Personal Access Token** support for private repositories and bypass of rate limits.
- Recursively parses Git Trees, performs multi-framework dependency resolution, and renders live topologies within milliseconds.

### Gateway 02: Local Workspace & Codebase-Memory-MCP (CBM) Engine
- Direct bridge with local file trees and the high-performance C-based `codebase-memory-mcp` daemon.
- Leverages 162 vendored Tree-sitter grammars, in-memory SQLite storage, and **Hybrid LSP** semantic type resolution.
- Instant 1-click loading of local cached databases (`~/.cache/codebase-memory-mcp/`).

### Gateway 03: Architectural Presets & Custom AST Ingestion
- Pre-computed architectural universes:
  - **Sketion Engine:** 568 entities, 1,520 relations, 7 architectural threats.
  - **Neo-API Gateway:** 312 entities, 840 relations, distributed microservice routing.
- Drag-and-drop dropzone for custom JSON AST graphs and compiler exports.

## 5. Visual Architecture & 2.5D Graphics Engine

- **Procedural Height & Spire Scaling:** Building height dynamically scales from 12px (utility functions) to 110px (God-class monoliths) based on LOC and cyclomatic mass.
- **Illuminated Window Matrices:** Facets render real-time glowing windows indicating internal algorithmic complexity.
- **Skyward Light Beams:** Landmark entities (`rarityScore >= 95`) project vertical neon beams into the stratosphere.
- **Screen-Space Anti-Collision Labels:** Badges render at constant 10.5px in screen-space with spatial priority culling, eliminating giant text scaling bugs during deep zoom.
- **Hierarchical Edge Bundling:** Groups multi-edge connections into smooth quadratic energy conduits with animated data packets, preventing laser floodlight glare.

## 6. Operational Decks & Simulation Tools

### 01 // World Map & Camera Controls
- **4-Tier Semantic Zoom:** Smooth navigation from Galaxy Macro Overview (0.05x) down to Internal Statement Level (12.0x).
- **Radar Minimap:** Real-time topologic HUD displaying active biomes, camera viewport frustum, and density distribution.

### 02 // CodeDex Knowledge Progression
- Tracks architectural discovery percentage across the codebase.
- Assigns XP and ranks (*Junior Explorer* to *Chief Architect*) upon exploring critical landmarks and completing refactoring missions.

### 03 // Procedural Mission Engine
- Generates tailored architectural quests based on actual static analysis findings:
  - *Decouple the God Class*
  - *Break the Cyclic Wormhole*
  - *Safeguard the Single Point of Failure*

### 04 // Threat Arena & Refactor Strategy Simulator
- Detects architectural anti-patterns:
  - **The Death Star:** Monolithic god components with dangerous fan-out.
  - **The Cyclic Wormhole:** Direct circular dependencies causing execution deadlocks.
  - **The Single Point of Failure:** Critical choke points with zero redundancy.
- Simulates 4 non-destructive decoupling strategies:
  - `[ BREAK CYCLE ]`
  - `[ SPLIT MODULE ]`
  - `[ INTRODUCE INTERFACE (DIP) ]`
  - `[ ISOLATE SERVICE ]`

### 05 // What-If Blast Radius Simulator
- **4 Cascade Scenarios:**
  - *Total Service Outage* (Downstream transitive failure).
  - *Network Latency Spike* (500ms delay propagation).
  - *Breaking API Change* (Direct caller signature failure).
  - *Security Breach Quarantining* (Blast isolation).
- Displays comparative before-vs-after risk reduction telemetry (e.g. `-40% Risk`).

### 06 // Dijkstra Trace Path GPS
- Select any Origin module and Destination module.
- Computes the shortest dependency call path and dispatches animated camera flights and glowing particle packets along the exact trajectory.

## 9. Security & Privacy

- **100% Local Execution:** All parsing, graph calculations, and simulations run entirely within your local browser runtime and local server.
- **Zero Data Retention:** No source code, metadata, or tokens are ever sent to third-party servers. GitHub tokens are kept in memory solely for direct authenticated calls to `api.github.com`.
